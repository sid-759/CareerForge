# CareerForge 🚀

### AI-Powered Career Preparation Platform

CareerForge is a full-stack web application that helps students and job seekers improve their interview readiness through resume analysis, ATS scoring, job description matching, AI-powered mock interviews, and personalized learning roadmaps.

---

## Features

### Resume Analysis

* Upload and analyze resumes
* Extract technical skills automatically
* Identify strengths and improvement areas
* ATS compatibility scoring

### Resume vs Job Description Match

* Compare resumes against job descriptions
* Generate match percentage
* Detect missing skills and keywords
* Provide actionable recommendations

### AI Mock Interview Simulator

* Generate role-specific interview questions
* Technical and behavioral interview practice
* AI-powered answer evaluation
* Performance feedback and scoring

### Learning Roadmap

* Identify skill gaps
* Generate personalized study plans
* Recommend learning priorities

### User Dashboard

* Track interview performance
* Monitor career readiness
* Review previous analyses

## Installation

Clone the repository:

```bash
git clone https://github.com/sid-759/CareerForge.git
```

Install dependencies:

```bash
npm install
```

Create a .env file:

```env
GEMINI_API_KEY=your_api_key
```

Run the application:

```bash
npm run dev
```
